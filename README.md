# 🌎 Görseller Üzerinden
# Geri Dönüşüm Tespit Etme
Proje Amacı:
Bu proje, görselleri analiz ederek geri dönüştürülebilir veya geri dönüştürülemez olduğunu tespit etmeyi amaçlamaktadır. Bir de bazı geri dönüşüm materyallerin hangi grupta olduğunu tespit etmek için.

## 🌠 Nasıl Çalışır?
### Model Eğitimi:

* Google Teachable Machine kullanılarak bilgisayarlı görü modeli eğitilir.

* Model, görselleri iki kategoriye ayırmak üzere eğitilir.

* Eğitimde kullanılan algoritma, görüntü sınıflandırması yapmak için makine öğrenmesi tekniklerini içerir.
